# Inheritance Hypothesis Testing

## Purpose

The ranking layer compares candidate disease models rather than assuming one
genotype pattern in advance. Every candidate is represented as an inheritance
hypothesis with variant-level, gene-level and model-level evidence.

## Hypothesis classes

| Class | Required candidate pattern | Main uncertainty |
|---|---|---|
| Compound heterozygous | Two credible heterozygous variants in the same gene | Whether the alleles are in trans |
| Homozygous recessive | One rare damaging homozygous variant | Call reliability and phenotype fit |
| Single heterozygous | One rare damaging heterozygous variant | Dominant mechanism or missing second allele |
| Mosaic | Low-VAF variant with reproducible alternate-read support | Germline imbalance or sequencing artifact |
| CNV/SV | Event-level depth, breakpoint or allele-balance signal | Event resolution and gene interpretation |

Parental genotypes are unavailable. De novo status and trans configuration
therefore remain unresolved unless supported by local phase or read evidence.

## Evidence model

Hypotheses are compared using the same evidence dimensions:

| Dimension | Examples |
|---|---|
| Technical | FILTER, QUAL, DP, GQ, allele depth, VAF, MQ and bias metrics |
| Population | Maximum observed population allele frequency |
| Functional | Consequence, impact, splice effect and coding change |
| Clinical | Pathogenic, benign or conflicting classifications |
| Phenotype | HPO semantic similarity and phenotype-group coverage |
| Inheritance | Genotype compatibility, allele count and phase evidence |

Missing population frequency is neutral rather than evidence of rarity.
Conflicting pathogenic and benign labels do not receive a pathogenic bonus.

## Candidate pools

Separate retrieval pools prevent one model from excluding another by
construction:

```text
Pool A: rare functional heterozygous variants
Pool B: rare functional homozygous variants
Pool C: low-VAF review candidates
Pool D: CNV/SV event candidates
Pool E: clinically significant variants
```

All pools use normalized variant identifiers and publish candidates to the same
hypothesis-ranking layer.

## Pair generation

Compound-heterozygous candidates are generated by joining heterozygous variants
within the same gene. A pair is retained only when:

- both component calls satisfy technical thresholds;
- both variants have compatible rarity and functional evidence;
- neither component is clearly benign;
- local phase does not place both variants in cis;
- the pair is not a short-range normalization or haplotype artifact.

Unknown-phase pairs separated by less than 500 bases are excluded to reduce
pseudo-pairs produced by complex local variation. Greater separation is not
treated as proof of trans phase.

## Single and homozygous hypotheses

Homozygous candidates receive model support when the gene is compatible with a
recessive mechanism and the alternate genotype has credible read support.

Single heterozygous candidates are retained when clinical, functional or
phenotype evidence is strong. A lone allele in a recessive-only gene is
downgraded because a second causal allele has not been identified.

Pair components are not repeated as independent single hypotheses in the final
ranking.

## Artifact controls

The ranking layer excludes or downgrades:

- variants with unambiguously benign classifications;
- common variants receiving misleading pathogenic annotations;
- variants known to share the same phased haplotype;
- dense HLA-region haplotypes;
- short-range pseudo-pairs;
- duplicate transcript or normalized-allele representations;
- weak single alleles in recessive-only genes.

These controls operate before final rank diversification.

## Model comparison

Each hypothesis receives a normalized base score followed by an
inheritance-aware adjustment. Final selection:

1. ranks all hypothesis classes together;
2. removes duplicate variant representations;
3. limits repeated fallback hypotheses from the same gene;
4. preserves lower-ranked alternatives from different models;
5. maps the selected scores to descending EPCR values.

The scores are ranking values, not calibrated probabilities.

## Sensitivity analysis

The leading hypotheses were tested under:

- Top-500 and Top-2000 phenotype retrieval scopes;
- heuristic and equal HPO feature weights;
- neutral treatment of missing population frequency;
- pair-quality controls for cis phase and local clustering.

The BUB1B pair remained first across these configurations. The PEX5 homozygous
deletion remained the strongest alternative model.

## Residual uncertainty

Both BUB1B alternate alleles were observed in targeted Lane-1 reads, but their
phase remains unknown. The available single-end validation cannot establish
trans configuration, replace parental segregation, or fully evaluate the PEX5
deletion.
